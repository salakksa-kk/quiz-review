Steps to Execute & Install Your Multiple Choice PWA

1. Run Immediately on Desktop or Mobile

All 165 questions and answers across Chapters 1 to 11 are pre-compiled and embedded directly inside this single index.html file. Your progress (`unseenBankIds`, `mutedBankIds`, and `reviewBankIds`) is saved automatically in your device's localStorage.

2. Local Execution (Desktop)

  • Save this file as index.html in a folder on your computer.
  • You can double-click index.html to open it in any browser, or serve it locally for full PWA installation using VS Code Live Server or Python: python3 -m http.server 8000 and visiting http://localhost:8000.

3. Free Hosting for Mobile Offline PWA (GitHub Pages / Netlify / Vercel)

  • Netlify Drop (Fastest - 30 seconds): Go to app.netlify.com/drop and drag-and-drop the folder containing index.html. It gives you an instant https:// link.
  • GitHub Pages: Create a repository, upload index.html, and enable GitHub Pages in Settings → Pages.

4. Installing on Mobile (iOS & Android)

  • iPhone / iPad (Safari): Open your hosted URL in Safari, tap the Share button at the bottom, and tap "Add to Home Screen".
  • Android (Chrome): Open your hosted URL in Chrome, tap the three-dot menu, and tap "Install app" or "Add to Home screen".

Bank State Verification:

• A question never exists simultaneously in the Question Bank and Review Bank.

• Correct answers in Start New are muted until all Question Bank questions are seen, or moved to Review if you click Add to Bank.

• Correct answers in Review are removed from the Review Bank and returned to the main Question Bank for future cycles.
